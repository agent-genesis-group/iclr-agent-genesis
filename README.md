# AI Collectives — ICLR 2027 workshop website

Static, responsive workshop website prepared for `agent-genesis-group/iclr-agent-genesis`.

## Preview

Open `index.html` directly in a browser. No build tools, package installation, external fonts, or runtime dependencies are required.

## Edit

- `index.html`: all website content, dates, biographies, schedule, and links.
- `styles.css`: layout, colors, and responsive breakpoints.
- `script.js`: accessible mobile menu and navigation highlighting.
- `assets/`: speaker photos provided in the source archive, plus the original SVG favicon.

All asset paths are relative, so the site works at the repository GitHub Pages subpath.

## GitHub Pages

After these files are committed to the target repository, choose **Settings → Pages → Deploy from a branch**, choose the branch containing these files and **/(root)**, and save. The expected URL is `https://agent-genesis-group.github.io/iclr-agent-genesis/`, once publishing is enabled and deployment succeeds. This URL is not a claim that deployment has already happened. GitHub Pages availability for private repositories depends on the account plan.

## Content provenance and publication checklist

Content and five speaker photographs come from the supplied `ICLR_2027_Workshop___Theoretical_Foundations_of_AI_Collectives___Communication__Organization__and_Control (1).zip`, specifically `iclr2027_conference.tex`. The reference website informed the single-page structure and green/light visual treatment; its code, old event content, and assets were not copied.

- Event remains labeled a proposal; dates and program remain tentative.
- Four speakers are marked confirmed, and Asu Ozdaglar invited, matching the source.
- Eight organizers, four research themes, 54 listed committee members, submission tracks, dates, review rules, participation plans, and sponsor commitments are represented.
- Organizer photographs were not supplied; initials are used instead.
- The proposal contains a panel description but no panel slot in its timetable. The panel is therefore marked planned, time to be announced.
- Workshop-specific OpenReview URL, final template/policy links, accepted papers, recordings, and award application details were not supplied or verified. They are described as forthcoming, with no invented links.
- The proposal's internal editorial comments, TODOs, old website address, reviewer nominations, and archived `iclr2025/` material are not published.
- Confirm proposal acceptance, final date, speaker participation, sponsor commitments, committee participation, and submission resources when updating the public website.

The source archive is not included in the website so internal proposal drafts are not inadvertently published.
